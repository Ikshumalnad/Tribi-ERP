📋 How the file is read

  • BOM code: taken from the sheet name after Purchase — e.g. sheet Purchase-300044124028 gives BOM code 300044124028.
  • Item Code: a column containing Item Code or Code
  • Quantity: Qty or Quantity — the amount needed per one set
  • Optional: MPN / Part No, Manufacturer / Make / Brand, Description

💡 Item codes that are not in the item master yet are created automatically, so no row is skipped.

Rows with a blank item code, a non-numeric quantity, or a quantity of zero or less are ignored.
