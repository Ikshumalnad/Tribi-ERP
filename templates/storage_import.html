📋 Supported Columns & Format Guidance

Download Excel Sample (.xlsx)

The importer automatically detects headers across the first 20 rows and supports all standard column aliases:

  • Item Code: Item Code, Code, Item, Part Number, Part No, SKU, Material
  • Quantity / Stock: Physical Count, Qty, Quantity, Count, Stock, Available, Total Qty
  • Location (Optional): Location, Store Location, Bin, Rack, Warehouse (falls back to Default Location)
  • Description (Optional): Description, Desc, Item Name (auto-fills master if item is new)
  • MPN & Manufacturer (Optional): MPN, Manufacturer, Make, Brand

💡 Auto-Creation: If an item code does not exist in the master database yet, it will be automatically created without skipping any row!
