What the file needs

Column headings are matched by keyword, so spelling and order do not need to be exact. Only two columns are essential.

ColumnNeededMatched on
Item codeYesItem Name, Item Code, Code
StockYesStock, Closing Stock, Phy Stk, Qty
DescriptionNoItem Description, Description
UnitNoUnit, UOM
MPNNoMPN, Part No
LocationNoLocation, Bin, Rack
  • GRN Qty, Issued Qty, Rate and Value are ignored — they are movements and money, not a stock balance.
  • MPN splits on a spaced hyphen. Keltron - SA1011EMAS gives manufacturer Keltron, part SA1011EMAS. A part number containing hyphens, like ACPL-M61L-060E, is left whole.
  • Missing manufacturers and units are created. num becomes pcs, mts becomes m, kgs becomes kg.
  • Quantities are added to whatever the item already holds.
