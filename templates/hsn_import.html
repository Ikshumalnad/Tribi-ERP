If you give only the total rate, cgst and sgst are filled as half each and igst as the whole — the same pattern as the codes already in this database. Give the columns explicitly to override that.
item_code is worth including. An HSN code on its own is just a tax rate on a list; the application finds an item's rate through the link between them.
Codes are matched on hsn_code. An existing one is updated rather than duplicated, and a blank cell never wipes a value already on record. Nothing is written until you confirm.
